# Sales-Dashboard
1. Project Title / Headline

Sales Performance Analysis Dashboard

2. Short Description / Purpose

An interactive Power BI dashboard designed to analyze sales performance across products, countries, and time periods. It helps track revenue, profit, cost, and sales distribution to support business decision-making.

3. Tech Stack
Power BI
Power Query (ETL)
DAX (KPIs & Measures)
Excel

 4. Data Source
Sales dataset (Excel file containing product-wise, country-wise, and yearly sales data including revenue, cost, profit, and units sold)

 5. Features / Highlights
🔹 Business Problem

Understanding sales performance across regions and products to identify profitable areas and improve decision-making.

🔹 Key Questions
Which products generate the highest revenue?
How do revenue and profit vary across countries?
What is the cost vs revenue comparison by region?
How are units sold distributed among products?

🔹 Dashboard Highlights
Revenue trend analysis by product and year
Country-wise comparison of revenue and profit
Cost vs revenue analysis across regions
Product-wise sales distribution using pie chart
Clear visual insights for business performance tracking
